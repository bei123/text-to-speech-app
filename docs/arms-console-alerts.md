# ARMS 用户体验监控 — 控制台告警配置指南

SDK 白屏检测已在 `src/plugins/armsRum.js` 中启用。告警规则需在阿里云控制台创建，无法通过前端代码配置。

官方文档：

- [管理告警规则](https://help.aliyun.com/zh/arms/user-experience-monitoring/manage-alarm-rules)
- [阈值检测](https://help.aliyun.com/zh/arms/user-experience-monitoring/threshold-detection)

## 前置：通知策略（只需配置一次）

1. 登录 [ARMS 控制台](https://arms.console.aliyun.com/)
2. 左侧 **告警管理** → **通知策略**（或 **联系人/通知组**）
3. 新建通知策略，绑定：
   - 钉钉群机器人 Webhook，或
   - 短信 / 邮件 / 电话联系人
4. 记下策略名称，创建告警规则时选用

## 创建告警规则

路径：**用户体验监控** → **告警规则** → **创建告警规则**

- **告警检测类型**：阈值检测
- **告警应用**：选择本项目的 Web & H5 应用（`tts` 对应的应用）
- **环境筛选**（如有）：`env = prod`

以下建议创建 **5 条独立规则**，便于分级通知。

---

### 规则 1：JS 异常突增（P2）

| 项 | 建议值 |
|----|--------|
| 告警名称 | `TTS-Web-JS异常突增` |
| 指标类型 | 异常类 / JS 错误（以控制台实际名称为准） |
| 触发周期 | 最近 5 分钟 |
| 告警指标 | 异常数量 |
| 触发条件 | 平均值 ≥ 10（先用「填入 P4 建议阈值」，再按「告警数预测」微调） |
| 告警等级 | P2 |
| 通知策略 | 钉钉群 |

---

### 规则 2：白屏（P1）

白屏事件由 SDK `whiteScreen` 上报，需在控制台选择 **白屏** 相关指标。

| 项 | 建议值 |
|----|--------|
| 告警名称 | `TTS-Web-白屏` |
| 指标类型 | 白屏 |
| 触发周期 | 最近 5 分钟 |
| 告警指标 | 白屏次数 / 白屏率（以控制台为准） |
| 触发条件 | ≥ 3 次（或白屏率 ≥ 5%，按业务量调整） |
| 告警等级 | P1 |
| 通知策略 | 钉钉群 + 关键联系人 |

---

### 规则 3：API 请求失败（P2）

| 项 | 建议值 |
|----|--------|
| 告警名称 | `TTS-Web-API失败` |
| 指标类型 | API / 资源 |
| 筛选条件 | 域名包含 `backend.2000gallery.art` |
| 触发周期 | 最近 5 分钟 |
| 告警指标 | API 错误数 或 错误率 |
| 触发条件 | 错误数 ≥ 20，或错误率 ≥ 10% |
| 告警等级 | P2 |

---

### 规则 4：LCP 过慢（P3）

| 项 | 建议值 |
|----|--------|
| 告警名称 | `TTS-Web-LCP过慢` |
| 指标类型 | Web Vitals / 性能 |
| 触发周期 | 最近 10 分钟 |
| 告警指标 | LCP（最大内容绘制） |
| 触发条件 | P75 或 平均值 ≥ 4000 ms |
| 告警等级 | P3 |

参考：[Web Vitals 说明](https://help.aliyun.com/zh/arms/user-experience-monitoring/view-monitoring-dashboard)

---

### 规则 5：页面完全加载过慢（P3）

| 项 | 建议值 |
|----|--------|
| 告警名称 | `TTS-Web-页面加载慢` |
| 指标类型 | 页面性能 |
| 触发周期 | 最近 10 分钟 |
| 告警指标 | 页面加载耗时 / FCP |
| 触发条件 | 平均值 ≥ 8000 ms（按实际调整） |
| 告警等级 | P3 |

---

## 验证告警

1. 部署带 ARMS SDK 的前端后，在 **数据探索** 中确认有 PV、异常、白屏等数据
2. 创建规则后点击 **告警数预测**，看预估触发次数是否合理
3. 可临时把阈值调低做联调，确认钉钉/邮件能收到通知后再调回

## 与本项目 SDK 的对应关系

| SDK 配置 | 作用 |
|----------|------|
| `whiteScreen.detectionRules` | 路由切换 / 加载后采样 `#app`，忽略 `#/login` |
| `filters.resource` | 不上报 `/encryption-key` |
| `filters.exception` | 过滤跨域 `Script error` 噪声 |
| `evaluateApi` | 上报 API 时剔除 Token / 签名头 |

环境变量（可选）：

```env
VUE_APP_ARMS_WHITE_SCREEN_DELAY=4000
```
